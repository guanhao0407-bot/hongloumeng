# 原著证据：版本、定位与核验

## 流程

1. 确认使用者提供的版本、章节和可讨论进度；如果只读前八十回，后续相关内容须另行询问是否讨论。
2. 文本提供后，结合实际阅读环境检查其目录与内容。可用 `scripts/epub_reader.py` 本地识别使用 NCX 目录且每回或合回一个独立文件的 EPUB、检索短片段。它不需要网络，不写入原书，也不建立自动课堂档案。
3. 对每条依据记录：版本信息、回目或合回、正文／校注、定位方式、核验状态。脚本输出段落号只是解析器计数，不是书中页码或稳定的跨版本编号。
4. 精确关键词只能寻找包含该字词的段落；未命中不等于作品没有相关内容，也不能证明人物没有行动。别名、隐含主体、上下文、章节内多处出现、图像字形都可能造成遗漏。回到阅读器前后文核实，并在教学解释中区分文本细节与推断。
5. 脚本将 class 为 note 的段落标为校注，其他 p 元素暂归正文；此启发式只对经核对的格式可靠，无法自动识别所有书、批语或注释，应与版面核对。有嵌入图片时用“〔图像内容或字形待核〕”标记，不能当成原文。NCX、HTML 结构或编码不兼容时停止并说明。

## 目录合回与阅读范围

如果目录将多回合并为一个文件，脚本报告目录覆盖的首尾回目，不将某段擅自分配为其中一回。为防止显示未读内容，只有当用户允许的范围完整包含该合回时才检索；否则跳过并列入 `skipped_partial_sections`。若选择范围中没有任何完整项，会报错，需要用户确认能否扩大范围或提供选段。

## 已核对的文件格式示例

项目开发期间曾对使用者提供的人文版校注 EPUB 作本地检验：版权页为人民文学出版社第三版、2019年10月第77次印刷，ISBN 978-7-02-000220-7；目录含119个正文目录项，覆盖120回，其中第十七至十八回合为一项。校注凡例对前八十回和后四十回分别说明了底本；后四十回在该版署为无名氏续，程伟元、高鹗整理刊行。本信息仅用于识别这一版，不替代其他版本信息，项目不提供原书或校注全文。

## 命令示例

在技能文件夹内执行，路径与关键词替换为用户实际提供的内容：

```text
python scripts/epub_reader.py "书的路径.epub" inspect
python scripts/epub_reader.py "书的路径.epub" search --query "关键词" --from-chapter 1 --to-chapter 80 --scope text --limit 5
python scripts/epub_reader.py "书的路径.epub" search --query "关键词" --from-chapter 2 --to-chapter 2 --scope note --limit 5
```

`inspect` 输出元数据、文件哈希、章节覆盖、解析字符数与图像标记数，不输出全书；`search` 返回匹配段落计数及至多指定数量的短片段，默认只搜索正文且最多12条。显示内容可能包含剧透或敏感素材；在了解学生已读范围后使用。两者仅向本地标准输出写结果；不创建数据库，不改变或上传 EPUB。不可把校注版上注明的印刷日期自动等同为电子版出版日期或其他书籍版本。
